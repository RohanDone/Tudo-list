# React To-Do List Application

A simple and interactive To-Do List application built using React.js. This project helps users add, view, complete, and delete daily tasks with a clean and responsive user interface. It demonstrates core React concepts such as components, state management, and event handling.

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Real-time UI updates
* Simple and responsive design

## Tech Stack

* **Frontend:** React.js, JavaScript
* **Styling:** CSS
* **Tools:** Node.js, npm, Git, GitHub

## Setup Instructions

1. Clone the repository
2. Run `npm install`
3. Run `npm start`
4. Open `http://localhost:3000` in browser
